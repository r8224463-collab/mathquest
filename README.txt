MathQuest - install steps (one time, ~5 minutes)

1. Unzip this folder.
2. Host the files at any free HTTPS link. Easiest options:
   - Netlify Drop: go to app.netlify.com/drop and drag the unzipped folder in.
   - GitHub Pages: new public repo -> upload all files -> Settings > Pages > deploy from main.
3. Open the link in Chrome on your phone -> menu (three dots) -> "Install app" / "Add to Home screen".
4. Open MathQuest from the home screen. It works offline and saves progress on the phone.

Your progress is stored on the device only. Use Settings > Export backup regularly.
